# بانانا 🍌

لعبة الكروت "Banana" على الموبايل — العب ضد روبوتات أو مع صحابك بكود أوضة.

- `src/engine.js` — كل قواعد اللعبة
- `src/bot.js` — الروبوتات (سهل/متوسط/صعب)
- `src/app.js` — الشاشات
- `src/net.js` + `src/store.js` — اللعب أونلاين (Firebase Realtime Database)
- `test/` — الاختبارات: `npm test`
